# Data attribution and transformations

## UCI Online Retail

Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5BW33

Source page: https://archive.ics.uci.edu/dataset/352/online-retail
Licence: Creative Commons Attribution 4.0 International,
https://creativecommons.org/licenses/by/4.0/

The original workbook is downloaded locally on a full build. It is not included
in the public repository. Aggregate exports, charts and segment totals are
adaptations. Source hashes are recorded. Cleaning and exclusion rules appear in
the project README and code. Demo transactions are generated independently and
do not copy source customer records.
No endorsement by the creator or UCI is implied.

## UCI Iranian Churn

Iranian Churn [Dataset]. (2020). UCI Machine Learning Repository.
https://doi.org/10.24432/C5JW3Z

Source page: https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset
Licence: Creative Commons Attribution 4.0 International,
https://creativecommons.org/licenses/by/4.0/

The original CSV is downloaded locally on a full build. It is not included in
the public repository. Only aggregate evaluation diagnostics are published.
Predictions and partition assignments are generated locally. The five scoring
examples and demo inputs are invented, not copied from source customers. The raw
source includes age, status and derived value columns that the model excludes.
No endorsement by UCI is implied.

## Synthetic demonstrations

All demo retail, demo churn and logistics observations are generated in this repository.
They are not sourced from a business, carrier or government dataset. Code and
synthetic outputs use the repository's MIT licence.

## Separation from code licence

The MIT code licence does not replace the CC BY 4.0 licence of the public datasets
or remove their attribution requirements. Preserve this file when redistributing
the sample, full churn CSV or derived outputs.
