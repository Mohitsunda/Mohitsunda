1. Clone the repository using its verified GitHub URL.
2. Follow `PORTFOLIO.md` to install and run the projects.
3. Create a branch for future changes. Update affected code, assumptions and results.
4. Run static checks, tests and notebook execution before opening a pull request.
5. Review the real Actions result before describing hosted CI as passing.
