# Contributing

Use Python 3.12 and install the development lock. Run `make check` and
`python scripts/execute_notebooks.py` before proposing changes. Record any source,
metric or assumption change in the corresponding data dictionary and case study.

Keep demo and full outputs separate. Never add credentials, personal customer
files, local model pickles or raw source downloads to Git. Update precomputed
outputs when analysis changes and explain material result differences in the PR.

This repository demonstrates research and analytical methods. Avoid claims of
real operational impact based on model scores or synthetic scenario outputs.
